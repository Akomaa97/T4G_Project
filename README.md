# The Love Project

A responsive static website for The Love Project, a child welfare charity focused on care, education, mentorship, and community support.

## Pages

- Home
- About
- Programs
- Volunteer
- Donate
- Gallery
- Contact

## Project Structure

```text
T4G_Project/
├── index.html
├── css/
│   └── style.css
├── images/
├── js/
└── pages/
    ├── about.html
    ├── contact.html
    ├── donate.html
    ├── gallery.html
    ├── programs.html
    └── volunteer.html
```

## Run Locally

No build tools are required. Open `index.html` in a web browser, or use a local server such as the VS Code Live Server extension.

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
